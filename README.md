# NEXORA WhatsApp Community Assistant

NEXORA WhatsApp group moderator + knowledge assistant + private NEXORA account assistant.

## Free hosting target

This package is prepared for **Back4app Containers Free Web Deployment**. Back4app documents a free tier with no credit card required and Docker/GitHub deployment.

See `BACK4APP_FREE_NO_CARD.md` for the exact deployment steps.

## Features

- Link blocking for normal group members
- 3-strike removal policy by default
- Admins may post links
- Welcome messages
- NEXORA knowledge/FAQ assistant
- Optional AI answers
- Private NEXORA account linking and account commands
- Health endpoint for container hosting
- Dockerfile included

## Important

This uses Baileys, an unofficial WhatsApp Web library. Use a dedicated WhatsApp number and comply with WhatsApp rules. The bot must not be used for unsolicited bulk messaging.

Account-specific information is only returned in private chats after the member is linked through the NEXORA API.
